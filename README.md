📂 Manipulação de Arquivos com Pathlib (Python)

Este repositório reúne exemplos práticos usando a biblioteca pathlib do Python para trabalhar com arquivos e diretórios.

A ideia é mostrar, de forma simples e progressiva, como automatizar tarefas comuns — desde operações básicas até situações mais próximas do uso real.

🧠 O que é Pathlib?

O pathlib é uma biblioteca padrão do Python para manipulação de caminhos de arquivos de forma mais moderna.

Ele substitui o os.path e torna o código:

Mais fácil de ler
Mais seguro
Mais organizado
